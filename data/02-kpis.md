# KPIs — FinOps Cost Optimization Platform (MVP)

## Executive KPIs

1. Total spend (monthly)
2. Top 5 cost drivers (% of total)
3. Spend by environment (prod vs dev)
4. Unusual spend alerts (simple threshold-based)

## Engineering/FinOps KPIs (MVP)

1. Cost visibility coverage: % services included in dataset
2. Allocation coverage: % rows with environment populated
3. Waste signals detected:
   - NAT Gateway cost above threshold
   - EC2 share above threshold
   - Dev spend ratio above threshold
