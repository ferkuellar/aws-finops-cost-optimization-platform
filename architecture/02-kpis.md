# KPIs — FinOps Platform (MVP)

## Executive KPIs
1. Total spend
2. Top cost drivers (% of total)
3. Spend by environment (prod vs dev)
4. Spend by region
5. Unusual spend alerts (threshold-based)

## Engineering/FinOps KPIs
1. Visibility coverage: % services present in dataset
2. Allocation coverage: % rows with environment populated
3. Waste signals:
   - NAT daily spikes
   - EC2 spend share above threshold
   - dev/prod ratio above threshold
